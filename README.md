Todo List is a modern and responsive task management application built with HTML, CSS, and JavaScript. It helps users organize their daily tasks with a clean and intuitive interface. The application includes Dark Mode for a comfortable viewing experience, task categorization to keep todos organized, real-time search for quickly finding tasks, and sorting options to manage tasks more efficiently. It is fully responsive, providing a seamless experience across desktop, tablet, and mobile devices. The project focuses on creating a smooth user experience while demonstrating modern front-end development practices and clean UI design.

Features:

🌙 Dark & Light Theme
📝 Add, Edit, Delete Tasks
📂 Task Categories
🔍 Real-time Search
↕️ Sort Tasks
✅ Mark Tasks as Completed
📱 Fully Responsive Design
💾 Local Storage Support (Data persists after page refresh)
⚡ Clean and Modern User Interface
